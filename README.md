# SRP-Ground-DINO
This section focuses on implementing a DINO program based on this code: https://www.mathworks.com/help/vision/ug/perform-zero-shot-object-detection-using-grounding-dino.html
DINO (DIstillation with NO labels) focuses on detecting objects based on the given inputs.
Based on some of my observations, both types of codes are able to successfully detect the target objects, but they are prone to make false detections
Comparing the two type of programs, the Python codes are able to run at a faster framerate compared to MATLAB.
